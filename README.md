# CV — Johannelle Gnonlonfoun

CV d'une page au format A4, au style épuré et élégant.

- `index.html` : la source du CV (HTML/CSS, polices intégrées dans `fonts/`)
- `CV_Johannelle_Gnonlonfoun.pdf` : la version PDF prête à envoyer

## Modifier et réexporter

1. Modifier le texte dans `index.html`.
2. Ouvrir le fichier dans Chrome, puis faire **Imprimer → Enregistrer au format PDF**
   (format A4, marges « Aucune », cocher « Graphiques d'arrière-plan »).
